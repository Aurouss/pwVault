# PwVault 审核材料

个人密码管理 Windows 应用的需求设计材料，供审核。当前阶段只有文档和界面示例图，尚未开始开发。

## 文件

| 文件 | 内容 |
| --- | --- |
| [设计文档.md](设计文档.md) | 需求清单、总体方案、功能设计、安全设计、数据设计、界面设计、待确认事项 |
| [开发文档.md](开发文档.md) | 开发环境、技术栈、工程结构、接口、建表语句、打包与发布、测试计划、里程碑 |
| [ui/00-overview.png](ui/00-overview.png) | 全部界面的总览图 |
| `ui/01` – `ui/12` | 各界面示例图（1280 × 800，2 倍分辨率） |
| `ui/mockups/` | 示例图的 HTML 原型源文件与渲染脚本 |

## 建议的审核顺序

1. 看 [ui/00-overview.png](ui/00-overview.png)，对整体界面有个印象。
2. 读设计文档第 8 章“待确认事项”，对 8 个决定给出意见。
3. 读设计文档第 2 章“需求清单”，确认原始需求没有理解偏差，并决定 2.2 节的补充项要不要。
4. 其余章节按需细读。

## 重新生成示例图

改动 `ui/mockups/` 下的原型后执行（不需要安装任何依赖，调用本机 Edge 或 Chrome 截图）：

```powershell
node docs/ui/mockups/render.mjs            # 全部
node docs/ui/mockups/render.mjs main edit  # 只生成指定页面
```
